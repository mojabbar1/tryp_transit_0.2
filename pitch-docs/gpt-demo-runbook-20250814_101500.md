## Live Demo Runbook (Investors)

Timestamp: 2025-08-14 10:15:00

### Goal
- Show the core loop (trip → progress → reward) and explain how nudges drive behavior.

### Pre-demo checklist
- Environment: required env vars set; seed demo data.
- Local run: backend and frontend started; basic API smoke test.
- Devices: phone or emulator ready with location mock if needed.

### Setup commands (example)
- From project root:
  - ./start-app.sh
  - In `src`: ensure database reachable; run `pnpm test` passes.

### Narrative flow (6–8 minutes)
- 1) Home and quick value prop
- 2) Select a route/user and complete a trip
- 3) Show progress increase, highlight next-step nudge
- 4) Show a partner near the station and mock redemption
- 5) Summarize: timing + economics = behavior change

### Proof points to call out
- Context signals used (time-of-day, proximity, progress)
- Reward design (windows, thresholds)
- Early engagement metrics (CTR, completion)

### Contingencies
- If AI call fails: show cached/fallback nudge copy
- If location isn’t available: use pre-seeded trip completion

### Call to action
- Invite to pilot discussion and metrics alignment meeting

### Post-demo follow-up
- Send deck and 2-minute product video link
- Share proposed pilot KPIs and timeline
